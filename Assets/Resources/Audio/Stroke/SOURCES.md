# Stroke sounds: sources and licence

Every file here is cut from **"Water Paddle" by EpicWizard** on Freesound
(https://freesound.org/people/EpicWizard/packs/17730/): single paddle strokes in the water,
recorded with a Zoom H4 in the Okanagan, BC.

**Licence: Creative Commons 0 (public domain dedication),
https://creativecommons.org/publicdomain/zero/1.0/.** No attribution is required; it is
given here anyway.

`tools/stroke-sounds.py` rebuilds the files: it downloads Freesound's high-quality MP3
preview of each source, keeps the stated length from the stroke's onset, fades the end,
normalises the peak, and writes 48 kHz mono 16-bit WAV.
